# Cover images (optional, for the presentation)

Drop cover / banner images here, then uncomment the matching line in
`src/data/brandAssets.js`. Anything you don't add keeps twelve's built-in
cinematic gradient artwork, so cards never look broken.

Recommended: **landscape**, roughly **16:10** (e.g. 1280×800), **.jpg**.
These fill the card artwork, the listing hero, checkout and the access screen.

## Where to get images

- Each service's **brand / press kit** page often has approved promotional
  banners and product screenshots.
- Prefer neutral **product/brand banners** over specific movie/show key-art —
  those posters are separately copyrighted.
- You can also use your own screenshots of each product's home screen.
