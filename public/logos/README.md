# Brand logos (optional, for the presentation)

Drop official logo files here, then uncomment the matching line in
`src/data/brandAssets.js`. Anything you don't add keeps twelve's built-in
stylized wordmark, so the app always looks complete.

## Filenames (must match exactly)

Use **.svg** if you can (sharpest), otherwise **.png** with a transparent
background. Prefer the **white / light** version of each logo — they sit on
dark cards and dark artwork.

`src/data/brandAssets.js` too (e.g. `netflix: '/logos/netflix.png'`).

## Where to get official assets

- Each brand's own **Brand / Press / Newsroom** page usually offers logo
  downloads (e.g. search "<brand> brand assets" or "<brand> press kit").
- **Wikimedia Commons** (commons.wikimedia.org) has many brand logos as SVG.
- Simple-Icons (simpleicons.org) has clean monochrome SVGs for most of these —
  good when you want a uniform white logo set.
